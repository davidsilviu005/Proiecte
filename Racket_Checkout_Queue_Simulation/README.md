# Checkout Queue Simulation in Racket

A functional simulation of supermarket checkout counters, developed over four independent stages. Customers are assigned to eligible counters, service time advances, and later stages add a queue abstraction and counter opening/closing.

| Stage | Main addition |
| --- | --- |
| [Stage 1](Stage_1/) | Basic checkout counters and customer assignment |
| [Stage 2](Stage_2/) | Exit times, delays, and capacity management |
| [Stage 3](Stage_3/) | Abstract queue implementation and elapsed-time simulation |
| [Stage 4](Stage_4/) | Opening/closing counters and redistributing customers |

Each stage contains its own implementation and the provided checker. Run the stages independently with Racket from their respective folders. The original assignment templates, backup files, compiled files, and ZIP submissions are excluded from this portfolio copy.
