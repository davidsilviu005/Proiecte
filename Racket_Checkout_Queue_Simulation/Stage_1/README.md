# Stage 1 — Basic Checkout Assignment

Models checkout counters with total service time and a list of waiting customers. Implements counter updates, selection of the least busy eligible counter, and processing of a sequence of customer requests. The first counter is reserved for customers with at most five items.

## Files

- `etapa1.rkt`: simulation implementation
- `checker.rkt`: original stage checker

Run from this folder with Racket:

```bash
racket checker.rkt
```
