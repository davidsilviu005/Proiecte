# Working with Data in MATLAB and Octave

This folder groups three numerical computing exercises written as MATLAB and Octave functions.

## Projects

- `numerical_music/` generates sound from instrument and pattern data, analyzes spectrograms, and applies high-pass filtering and reverb. `studio.m` is the demonstration script and expects its audio and CSV input files in the working directory.
- `recommendations/` reads and preprocesses a ratings matrix, uses singular value decomposition, and ranks similar themes with cosine similarity through `recommendations.m`.
- `robotzii/` parses coordinate data and implements polynomial interpolation with a Vandermonde matrix and cubic spline interpolation, with plotting helpers for both methods.

Open the relevant folder in MATLAB or Octave and call its functions with the required input data. The data files referenced by some scripts are not included here.
